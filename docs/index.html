隐私政策使用说明
PERSONAL FILE SYNC

个人文件同步与备份

rclone-touyanshe 是供维护者本人使用的 Google 授权应用名称。它配合 rclone，在本人控制的设备、服务器与 Google Drive 之间传输、同步和备份文件。

阅读隐私政策
01 / 用途

同步所需的文件

根据维护者配置的任务，列出、上传、下载和更新文件；需要时移动或删除文件，以完成备份和同步。

02 / 控制

由本人授权与运行

文件操作由维护者设备或服务器上的 rclone 执行。Google 授权可随时在 Google 账号设置中撤销。

03 / 公开说明

清楚说明数据用途

本网站提供应用介绍和隐私政策，无登录或文件上传功能，不接收 Google 授权凭据或云盘文件。

Google Drive 访问权限

本应用使用 Google 的开放授权机制（OAuth 2.0），请求 https://www.googleapis.com/auth/drive 权限，以便对授权账号中的文件执行同步所需的读取、创建、修改和删除操作。应用不获取 Google 账号密码。

数据访问、存储、共享和删除方式见隐私政策。维护者可以在 Google 账号的第三方连接页面移除本应用的访问权限。

使用说明

本应用由 GitHub 用户 baiyening 维护，仅供维护者本人管理其拥有或有权处理的文件，不提供面向公众的注册或托管同步服务。维护者决定同步来源、目标及文件保留方式。

本页面介绍的是个人配置，不是 Google 或 rclone 官方网站。rclone 项目说明见 rclone.org。

联系维护者

应用及隐私问题可通过 GitHub Issues联系维护者。涉及私密内容时，请使用 Google 授权页面列出的用户支持邮箱，不要在公开问题中提交云盘文件、密码或授权凭据。
