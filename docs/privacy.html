隐私政策

应用：rclone-touyanshe · 生效及更新日期：2026 年 11 月 8 日

本政策说明 rclone-touyanshe 如何处理 Google 用户数据，以及本说明网站的访问数据。本应用由 GitHub 用户 baiyening 维护，供维护者本人使用 rclone 进行文件同步和备份，不提供公众注册服务。

1. 访问哪些数据

经账号所有者授权后，rclone 使用 Google Drive 应用程序接口（API）访问本应用获准使用的文件数据，包括这些文件和文件夹的名称、标识符、路径、大小、修改时间、校验信息、相关文件属性，以及任务涉及的文件内容。

本应用仅请求 https://www.googleapis.com/auth/drive.file 权限，访问范围限于本应用创建或账号所有者明确授权给本应用使用的文件和文件夹。应用可在此范围内列出、读取、创建、更新、移动和删除文件；该权限不授予读取或管理账号中其余既有文件的能力。Google 的开放授权机制（OAuth 2.0）提供访问令牌和刷新令牌；本应用不获取 Google 账号密码。

2. 数据用途与限制

数据仅用于维护者配置的文件传输、同步、备份、恢复，以及相关任务状态检查和故障排查。具体操作取决于维护者执行的命令和任务配置。

本应用不出售 Google 用户数据，不为广告投放、用户画像或训练通用人工智能模型而收集这些数据。通过 Google API 获得的信息，其使用和转移遵守 Google API 服务用户数据政策，包括限制使用要求。

3. 数据存储与保护

rclone 在维护者指定的设备或运行环境中运行，其中可能包括第三方平台托管的任务环境。授权令牌保存在相应运行环境的 rclone 配置或凭据存储中；文件按任务配置保存在 Google Drive、本地设备或维护者指定的存储目标。任务日志可能包含获准访问的文件名称、路径、传输状态和错误信息。

Google API 通信使用 HTTPS 加密传输。设备、配置、日志和目标存储的访问由维护者管理。授权令牌、客户端密钥和云盘文件不发布到本网站或公开代码仓库。

4. 共享与第三方服务

文件操作所需的数据会传送至 Google、维护者明确配置的源或目标存储服务，以及维护者指定的任务运行环境。使用第三方托管环境时，该环境可能接收并保存完成任务所需的授权凭据、文件和日志。本应用不为广告、数据交易或与文件操作无关的用途向第三方提供 Google 用户数据。Google、存储服务和托管平台分别按其自身隐私政策及账号设置处理接收到的数据。

本公开网站由 GitHub Pages 托管，只提供应用说明，不运行 Google 登录或文件传输功能，不接收云盘内容及授权令牌。

5. 数据保留、删除与撤销授权

  • 同步或备份的文件保留到维护者主动删除，或由其配置的同步及保留规则删除为止；本应用不设置统一的自动删除期限。
  • 配置中的授权令牌保留到维护者删除相应凭据为止。账号所有者可随时在 Google 账号的第三方连接页面移除 rclone-touyanshe 的访问权限，使授权失效。
  • 撤销授权会阻止后续使用该授权访问 Google Drive，但不会自动删除已经复制的文件、运行日志或配置。彻底清理时，需要分别删除运行设备中的配置、日志，以及各存储位置的文件副本，并按需要清空对应回收站。

6. 网站访问数据

本网站不添加广告、访问统计脚本、跟踪 Cookie 或数据收集表单。作为托管提供方，GitHub 可能为提供服务和保障安全处理网络地址及请求等技术信息，详见 GitHub 隐私声明。点击外部链接后，适用目标网站的隐私政策。

7. 联系与政策更新

应用及隐私问题可通过 GitHub Issues联系维护者；涉及私密内容时，请使用 Google 授权页面列出的用户支持邮箱。请勿在公开问题中提交云盘文件、密码、密钥或授权令牌。

如数据处理方式改变，维护者会先更新本政策及页面日期；涉及新的数据用途或访问权限时，在处理前取得相应授权。
